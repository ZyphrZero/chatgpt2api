欢迎使用 DF Image

DF Image 是面向图片创作的多模型工作台。你可以使用 QQ / 微信 / 抖音 聚合授权登录，无需单独注册账号；首次登录后，系统会自动创建用户并按后台规则发放体验额度。

建议新用户先从以下路径开始：
登录 → 进入 创作台 → 输入提示词 → 选择比例 / 分辨率 / 质量 → 生成 → 下载 / 分享 / 加入参考图继续改图。

一、登录与账号

  • 普通用户入口： 使用 QQ、微信或抖音授权登录，授权成功后自动进入站内。
  • 管理员入口： 管理员使用独立的 /admin-login 页面，通过密钥直登后台。
  • 邀请关系： 通过邀请链接进入的用户，会自动绑定邀请码；登录完成后会按后台配置发放 注册赠送、邀请人奖励、被邀请人奖励。
  • 每日签到： 在站内顶部可见签到入口，签到后额度会实时同步到当前账号。

二、创作模式

  • 对话： 适合连续描述、改稿、追问风格、补充细节。
  • 作画： 直接生成图片，适合快速出图与批量测试。
  • 参考图 / 编辑： 上传图片后可继续做同风格改图、局部延展、人物设定统一、版式变体等。
  • 提示词市场： 可一键套用公开提示词模板，再结合你自己的主题微调。

三、参数怎么选

1. 比例

  • 1:1：头像、图标、商品主图。
  • 3:2 / 4:3：摄影感、海报、产品图。
  • 16:9：横版封面、PPT、展示图。
  • 9:16：手机壁纸、短视频封面、竖版海报。
  • 21:9：超宽横版、电影感全景、官网头图。

2. 分辨率

  • Auto：适合日常测试，速度更快。
  • 1080P：适合快速出图与低成本试稿。
  • 2K：适合正式分享、海报、小型印刷。
  • 4K：适合高质量细节图，但耗时更长，超宽比例下可能明显增加等待时间。

3. 质量 / 格式

  • High：更适合最终出图，但耗时通常高于 Medium / Low。
  • PNG：通用、细节稳定、便于二次编辑。
  • JPEG / WebP：体积更小，适合网页传播与下载分享。

实战建议： 先用 Auto + Medium/High 快速试稿，满意后再升到 2K / 4K 做最终版本。

四、参考图与连续创作

  • 上传参考图后，系统会把图片与提示词一起提交，适合做 风格迁移、角色一致性、海报重绘、局部改稿。
  • 图片生成成功后，可使用 加入参考图 把当前结果继续送入下一轮。
  • 如果你想“在上一张的基础上改一点”，建议保留上一轮描述，再补一句新的修改要求。

五、结果页能做什么

  • 原图： 查看当前结果的大图。
  • 分享： 创建分享页并自动带出同款生成入口。
  • 公开 / 私有： 控制图片是否进入公开图库。
  • 重新生成： 使用当前轮提示词再次出图。
  • 生成相似： 在当前结果基础上继续做风格接近的变体。

六、额度与奖励

  • 注册赠送： 首次社交登录后自动发放。
  • 邀请奖励： 邀请人和被邀请人都会按后台规则获得额度。
  • 签到奖励： 每日签到可获得额外张数。
  • 高阶操作： 若站点启用了 2K / 4K 放大或其他增强功能，可能会额外扣除额度。

七、常见问题

1. 一直显示“等待生成结果”怎么办？

  • 优先查看任务提示：当前是 排队中、上游生成中 还是 正在同步结果。
  • 如果是 21:9 + 4K + High 这类组合，等待时间会明显增加，建议先降到 2K 或使用更常见的比例试稿。

2. 如果提示没有输出数据怎么办？

  • 通常表示上游没有在等待窗口内返回可下载结果，建议 降低分辨率、降低质量 或 简化提示词 后重试。

3. 为什么有些请求更慢？

  • 高分辨率、超宽比例、复杂提示词、多参考图、批量多张生成，都会提高整体耗时。

八、推荐使用策略

  • 试稿阶段： Auto / 1080P + 常规比例。
  • 定稿阶段： 2K / 4K + High + 明确构图要求。
  • 连续改稿： 优先使用对话或参考图模式，而不是每次从零描述。
  • 做分享图： 生成成功后优先使用分享功能，方便他人一键生成同款。

一句话总结：
先快速试稿，再高分辨率定稿；先生成，再参考图迭代；先用普通比例确认风格，再挑战超宽 4K 细节版。
